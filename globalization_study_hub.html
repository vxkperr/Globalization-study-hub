🎯 Study Strategies

1. Active recall

Hide the definition and try to explain the term from memory before checking the answer.

2. Spaced repetition

Review the same terms over several days instead of studying everything once.

3. Teach it

Explain globalization out loud as if you were teaching a friend. If you get stuck, that topic needs more review.

4. Make connections

Example: A phone can connect people through communication technology, depend on international trade, and affect the economy.

5. Compare terms

For similar terms, write one sentence explaining the difference. This is especially useful for assimilation, acculturation, affirmation, integration and marginalization.
